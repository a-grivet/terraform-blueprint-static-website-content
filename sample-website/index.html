Architecture Overview

Secure, scalable, and globally distributed static website hosting

☁️

CloudFront CDN

Global content delivery network with 400+ edge locations for low-latency access worldwide.

  • HTTP/2 & HTTP/3 support
  • Gzip/Brotli compression
  • Custom error pages
  • IPv6 enabled
🗄️

S3 Origin

Private S3 bucket with Origin Access Control (OAC) for secure content storage.

  • KMS encryption at rest
  • Versioning enabled
  • Public access blocked
  • Lifecycle policies
🔐

SSL/TLS Certificate

ACM certificate with automatic renewal and DNS validation via Route 53.

  • TLS 1.2+ enforced
  • Auto-renewal enabled
  • SNI support
  • HTTPS redirect
🌐

Route 53 DNS

Managed DNS service with health checks and automatic failover capabilities.

  • A and AAAA records
  • Global DNS network
  • Health monitoring
  • Low latency routing
